# Music-player🎵

A small pixel-art inspired desktop music player built with Electron, HTML, CSS and JavaScript.

The application allows users to play a collection of local music tracks using a simple and compact desktop interface.

## ✨ Features

- Play and pause music
- Skip to the next track
- Go back to the previous track
- Automatically plays the next track when a song ends
- Displays the current track name
- Displays custom artwork for each track
- Local music files
- Custom pixel-art inspired interface
- Frameless Electron window
- Transparent window
- Fixed window size
- Non-resizable window

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Electron
- Figma

## 🎨 Design

The music player uses a pixel-art inspired visual style with custom backgrounds, buttons and track artwork.

The interface is designed to be small and compact so it can function as a desktop music widget.
